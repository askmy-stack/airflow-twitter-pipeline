# Code of Conduct

This project follows the Contributor Covenant Code of Conduct.

## Expected behavior

- Be respectful and constructive.
- Assume good intent while keeping feedback specific and actionable.
- Keep discussions focused on improving the project.

## Unacceptable behavior

- Harassment, threats, or discriminatory language.
- Publishing private credentials, private data, or personal information.
- Repeatedly derailing technical discussions.

Maintainers may remove comments, close issues, or block participation when needed to keep the project safe and useful.
